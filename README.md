# 🧮 Calculadora em JavaScript (Node.js)

![JavaScript](https://img.shields.io/badge/JavaScript-ES6+-yellow?logo=javascript)
![Node.js](https://img.shields.io/badge/Node.js-22.x-green?logo=node.js)
![Status](https://img.shields.io/badge/Status-Concluído-brightgreen)

Uma calculadora simples desenvolvida em **JavaScript** para ser executada no terminal utilizando **Node.js** e o módulo nativo **readline**.

## 📌 Funcionalidades

- ➕ Soma
- ➖ Subtração
- ✖️ Multiplicação
- ➗ Divisão
- Tratamento de erro para divisão por zero

## 🚀 Tecnologias utilizadas

- JavaScript (ES Modules)
- Node.js
- Módulo `readline`

## 📂 Estrutura do projeto

```text
.
├── index.js
├── calculadora.js
└── README.md
```

## ▶️ Como executar

1. Clone este repositório:

```bash
git clone https://github.com/suzanawerdine/calculadora.git
```

2. Acesse a pasta do projeto:

```bash
cd calculadora
```

3. Execute o programa:

```bash
node index.js
```

## 💻 Exemplo de uso

```text
Digite o primeiro número:
> 10

Escolha a operação (+, -, *, /):
> *

Digite o segundo número:
> 5

Resultado: 50
```
